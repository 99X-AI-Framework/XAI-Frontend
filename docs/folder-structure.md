# Folder Structure

- `src/app`: application bootstrap, routing, providers, layouts, and navigation.
- `src/components`: reusable UI primitives and shared components.
- `src/features`: independently owned business modules.
- `src/config`: application configuration.
- `src/hooks`: cross-feature React hooks.
- `src/lib/api`: centralized HTTP client; `src/lib/utils`: shared utilities.
- `src/types`: cross-feature types; `src/styles`: global CSS; `src/assets`: static assets.
- `docs`: project architecture and contributor guidance.
